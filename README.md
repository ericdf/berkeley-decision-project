# Berkeley Decision Project

**Live site: <https://ericdf.github.io/berkeley-decision-project/>**

Better questions. Better evidence. Better choices.

Frameworks, methods, worked examples and proposals for improving how Berkeley makes
public decisions — evaluable independently of any judgment about an individual
officeholder.

## What this repository is

Generated publication output. **Do not author here.** Every page is built from the
private source repository and overwritten on each publish.

- **Source:** `ericdf/Berkeley-council-scorecards` (private)
- **Build:** `build_publications.py`, driven by `publications.json`
- **Publish:** `./publish-policy.sh` from the source repo

Page assignment between this publication and Council Scorecards is by editorial
purpose, recorded explicitly in `publications.json`, not inferred from paths.

## Related publication

[Council Scorecards](https://ericdf.github.io/council-scorecards/) assesses the conduct
and performance of Berkeley's elected officials against a disclosed methodology.

The two projects share research, source material and a commitment to documented
evidence, but serve different purposes and are published separately. This one develops
better approaches to public decisions; Council Scorecards evaluates officeholders.

## Corrections

Every figure on this site traces to a primary document. Where a figure could not be
reproduced from the source it is attributed to, it has been dropped and the omission
stated on the page. Pages carrying figures still being checked against their primary
source say so in their Sources footer.

Corrections are welcome and are published when received.
